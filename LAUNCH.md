# Launch and distribution

Live since 2026-11-22 at https://theguysaccount.github.io/democracys-org-democracy-scores/, beside https://democracys.org/.
Machine channels only.

| Channel | How |
|---|---|
| Search | Indexed: the home page ("democracy scores by country open data"), `/embed/` ("democracy score chart embed") and `/reproducibility/`. Country, ranking and data copies are `noindex` and point at democracys.org. |
| Embeds | Every chart links to the full democracys.org profile, so each embed is a referral loop to the live site. |
| IndexNow | Every deploy submits the indexable pages. |
| Account root | `theguysaccount.github.io/robots.txt` lists this sitemap within a day. |
| GitHub | Public repo with description, topics and README. |

## Domain

A subdomain of democracys.org (DNS at Namecheap), for example `data.democracys.org`, set up by the domain rollout
session. Exact records and settings: OPERATIONS.md ("Custom domain"). The democracys.org records are untouched.
